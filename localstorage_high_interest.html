4GTM実装コードサンプル社内CS・実装者向け
パターンA：訪問回数カウント（7日間）
GTM カスタムHTML タグ
// 全ページで発火するタグに設定
<script>
  (function() {
    var KEY = 'mico_visits';
    var now = Date.now();
    var days7 = 7 * 24 * 60 * 60 * 1000;

    // 既存の訪問ログを取得・7日以内のみ残す
    var raw = localStorage.getItem(KEY);
    var visits = raw
      ? JSON.parse(raw).filter(function(t) {
          return now - t < days7;
        })
      : [];

    // 今回の訪問を追加
    visits.push(now);
    localStorage.setItem(KEY,
      JSON.stringify(visits));

    // 閾値チェック → Micoイベント発火
    if (visits.length >= 5) {
      mc_tracker('EVENT',
        'high_interest_repeat', {});
    }
  })();
</script>
パターンB：ページ閲覧数カウント（1セッション）
GTM カスタムHTML タグ
// 全ページで発火するタグに設定
<script>
  (function() {
    var KEY = 'mico_pageviews';

    // セッション内PVをカウント
    var pv = parseInt(
      sessionStorage.getItem(KEY) || '0'
    ) + 1;
    sessionStorage.setItem(KEY,
      pv.toString());

    // 5ページ目で1度だけ発火
    if (pv === 5) {
      mc_tracker('EVENT',
        'high_interest_deepread', {});
    }
  })();
</script>
パターンC：滞在時間計測
GTM カスタムHTML タグ
// 全ページで発火するタグに設定
<script>
  (function() {
    var ACC_KEY = 'mico_total_sec';
    var FIRED_KEY = 'mico_hi_fired';
    var start = Date.now();

    window.addEventListener('pagehide',
      function() {
        var spent = (Date.now() - start)
          / 1000;
        var acc = parseFloat(
          localStorage.getItem(ACC_KEY)
          || '0') + spent;
        localStorage.setItem(
          ACC_KEY, acc);

        // 600秒超・未発火なら実行
        if (acc >= 600 &&
          !localStorage.getItem(
            FIRED_KEY)) {
          mc_tracker('EVENT',
            'high_interest_longstay',{});
          localStorage.setItem(
            FIRED_KEY, '1');
        }
    });
  })();
</script>
5注意事項・事前確認ポイント社内CS・実装者向け
⚠ LINE WebView とSafari で localStorage が分離される
LINEアプリ内ブラウザ（WebView）とSafariは別のlocalStorageを持つため、LINEからの遷移→Safariで再訪問した場合にカウントが引き継がれない。
対策：mc_tokenをURLパラメータで引き回し、訪問ログをサーバーサイドで管理する方法も検討。まずはLINE WebView内のみで完結するフローでPoC推奨。
⚠ iOS Safari プライベートブラウジングの制限
iOSのプライベートブラウジング時はlocalStorageの書き込みが制限・初期化される場合がある。
対策：try-catchでエラーをキャッチし、localStorageが使えない場合はsessionStorageにフォールバックする実装を推奨。
✓ GTMプレビューモードで動作確認できる
GTMのプレビューモード＋ブラウザ開発者ツール（Application → localStorage）で値の書き込みを目視確認できる。
確認手順：①GTMプレビュー起動 → ②対象ページを複数回遷移 → ③開発者ツールでlocalStorageの値が増えているか確認 → ④Networkタブでmc_trackerのeventが発火しているか確認。
✓ 重複発火防止フラグの設定を忘れずに
閾値を超えた後もページ遷移のたびにイベントが発火し続けることを防ぐため、「発火済みフラグ」をlocalStorageに保存する実装が必要。
実装例：上記パターンCのコードサンプル参照（FIRED_KEYで制御）。パターンA・BもMicoでのセグメント重複を防ぐため同様のフラグ処理を追加推奨。

複数回ページ遷移 → localStorageの値が増えるか確認 → 閾値超過時にmc_trackerのeventが発火するか確認（NetworkタブでStatus 200を確認）
4

イベント受信したユーザーをセグメント化 → ステップ配信（1日目・2日目・3日目）で訴求内容を変えながら集中配信。配信間隔・通数はクライアントと合意
5

公開後、実際にLINEから遷移して本番環境での動作を最終確認。Micoのカスタマー画面にイベントが記録されているかをあわせてチェック
